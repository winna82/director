# Director

Grok directs multi-shot coverage. Imagine rolls the film.

Sign in, write a scene brief, Call Director, then Roll camera. Next scene continues the same reel.

## Railway

1. New service from this repo
2. Add Postgres (`DATABASE_URL`)
3. Add a Bucket and connect it to the service
4. Set `BETTER_AUTH_SECRET` and `BETTER_AUTH_URL` (your public Railway URL)
